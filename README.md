# Power BI Journey: Building Dashboards That Drive Decisions

A showcase of my Power BI learning journey, from first reports to polished, interactive dashboards. Each project turns raw data into clear visuals that help people make decisions.

## 📖 Overview

This repository documents how I build dashboards in Power BI: connecting and cleaning data, modeling it, writing DAX measures, and designing reports that tell a story. It's both a portfolio and a record of how my skills have grown.

## 🛠️ Skills Demonstrated

- **Data connection & transformation**: Power Query, merging and cleaning data from Excel, CSV, and SQL sources
- **Data modeling**: star schema, relationships, and date tables
- **DAX**: measures, calculated columns, time intelligence (YTD, MoM, YoY), and KPIs
- **Visualization & design**: layout, color, interactivity, slicers, drill-through, and tooltips
- **Publishing & sharing**: Power BI Service, scheduled refresh, and sharing reports


## 🔄 My Workflow

1. **Understand the question**: define who the dashboard is for and what decisions it supports
2. **Get and clean the data**: Power Query transformations and quality checks
3. **Model the data**: build relationships and a proper date table
4. **Write measures**: DAX for KPIs and comparisons
5. **Design the report**: clear layout, consistent colors, and a logical flow
6. **Test and share**: validate numbers against the source, then publish

## 💡 Lessons Learned

-  A clean data model matters more than fancy visuals
-  Fewer visuals with a clear message beat crowded pages
- Always reconcile dashboard totals against the source data
